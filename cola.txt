CSS

Para fazer com que o css identifique que você está editando o html e vincula-lo, você usa a tag "link" dentro do html.

href é qual arquivo será linkado no css.

<link rel="stylesheet" href="index.css">

O link deve ficar abaixo do título principal da guia(Site). O "tittle". Sempre identifique se o arquivo que você inserir no href está dentro de uma pasta, pois é necessário adicionar o atalho.

para personalizar elementos do site3 com CSS utiliza-se a tag correspondente com o html. Por exemplo:
quero customizar "h1", portanto, no arquivo de css escreva h1, o programa vai identificar qual grupo você quer customizar/estilizar

EX:

h1
{
    color (cor do site) : white;
    font-size(tamanho da fonte do elemento que está estilizando): 40px; (px são pixels)

}

Em alguns casos é necessário adicionar mais de um "h2" ou "h3" etc... Para adicionar mais de um h2 no body do código basta adicionar "class" entre a criação da tag h2 e o fim dela.
EX:

<h2 class = "teste"> </h2>


div é um grupo, serve para separar os elementos do site em diferentes estilizações sem atrapalhar no código completo

EX:

<div> 
    <h1>Olá Pessoal!</h1>
</div>


Para personalizar a tag div, no caso, um grupo específico de elementos do site, escreva "div" dentro do css.
EX:

div{
    background-color: #white;
    border-radius: 20px;
}


Para centralizar os elementos do site no css utiliza-se: display e os seguintes códigos:

-------------------------------------------------------------------------------------------------------------------------------------
Esse bloco de código serve para centralizar perfeitamente qualquer elemento no meio da tela (tanto na horizontal quanto na vertical).

Em resumo:display: flex; Ativa o modo de alinhamento inteligente (Flexbox).

flex-direction: column; Empilha os itens de cima para baixo (em coluna).

align-items: center; Centraliza os itens na horizontal.

justify-content: center; Centraliza os itens na vertical.

EX:

div{
    display: flex; 
    flex-direction: column;
    align-items: center;
    justify-content: center;
}
-------------------------------------------------------------------------------------------------------------------
